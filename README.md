# tacosounds-updates

Version endpoint for TacoSounds products. Plugins read `version.json` to offer a
"new version available" notice. No user data is collected.

- `version.json` — TacoSounds IR Loader
- `amp_version.json` — TacoSounds Amp
- `irloader_catalog.json` — product catalog for TacoSounds IR Loader (names, categories,
  store links, preview clips, specs), so new products reach existing installs without an update.
  Generated by `Tools/gen_irloader_catalog.py`; the app only accepts a higher `revision`.

The same files are relayed at `https://link.tacosounds.com/irloader/…` once the custom domain is
live; the app reads both and uses the newer one.
